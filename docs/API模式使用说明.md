# API 模式使用说明

本轮改造范围是 API 模式。Agent 的长期记忆、联网搜索、服务器控制和 Push 模式不属于本轮新增功能。

## Manager 配置

在目标 VPS 的自动化身份页面创建身份，模式选择 API。内部名称用于建立稳定的用户与历史记录关联，显示名称与头像可修改。API 地址填写兼容 Chat Completions 的模型服务地址，例如 `http://127.0.0.1:8317/v1`；CLI Proxy API 管理页面链接用于打开管理页面。

配置 API 密钥、默认模型与按顺序排列的备用模型。独立对话可勾选多个模型，并拖动已选列表调整顺序；服务端从上到下尝试，成功后停止，全部失败时报告错误。只选择一个模型时仅调用该模型。清空已选列表即为自动选择：服务端先尝试 Manager 默认模型，再按备用模型的配置顺序依次尝试，重复名称只尝试一次。默认模型和备用模型都未填写时，才通过模型发现取得候选，并按返回顺序尝试。

客户端打开“模型与提示词”时，通过 `GET /api/automation/{id}/models` 合并预设模型与远端 `/v1/models` 目录。远端发现失败时仍可使用已配置模型；自动发现依赖模型服务提供兼容接口，不能保证每个返回的模型都有调用权限。

API 身份拥有两套独立的系统提示词：

- **@ 场景提示词**：默认说明当前是在多人聊天中被提及，要求结合发送者和时间理解上下文，只回答当前提问。
- **独立对话默认提示词**：初始为空。客户端每个独立对话可继承此项、单独覆盖，或明确清空。更改一个对话的提示词不会影响其他对话。

Manager 还提供独立的“对话标题总结提示词”，默认要求根据首轮对话生成简短标题；它只用于标题生成，不会作为正常聊天的系统提示词。

默认上下文预算是 **60,000 个 Unicode 字符**，包括正文、发送者名称、发送时间及元信息。按最近内容保留，超出时先裁剪最旧内容，不再固定限制为 30 条。字符数量不等于模型 token 数量：模型服务窗口较小或总提示词较长时，可在 Manager 调低预算。

在目标 VPS 的 **AI 与自动化身份** 页面，每个 API 身份卡片下方都有 **编辑系统提示词** 和 **编辑头像、名称与配置** 两个文字按钮。提示词入口会直接定位到对应区域，可修改 @ 场景、独立对话及标题总结提示词。弹窗保存先更新本机配置，随后点击页面顶部的 **上传并应用到 VPS** 写入目标服务器并重启生效。已单独覆盖提示词的客户端对话保持自身设置；继承默认值的对话在后续调用中使用新默认值。修改头像和显示名称后，客户端刷新联系人目录可取得新资料。

### 上传或替换 AI 头像

先更新目标 VPS 的服务端二进制，再点击身份卡片的 **编辑头像、名称与配置 → 选择头像**，支持 PNG、JPEG、WebP，大小不超过 5 MB。头像可先离线选择并保存到 Manager；关闭重开仍保留待上传路径，因此上传前请勿移动或删除原图片。连接目标 VPS 后点击 **上传并应用到 VPS**，Manager 通过 SFTP 上传，以 quickconect 服务账号导入配置指定的数据库和媒体目录，然后将头像 ID 写入身份配置并重启服务。无需手工填写媒体 ID。

本机保存与上传分开，未连接时不会因为无法上传而丢失身份编辑内容。服务端按文件内容检查图片类型；若提示需要新版服务端，请先在部署页更新服务端后重试。头像上传不更换服务器证书。

关闭独立对话、停用身份或取消某个用户的权限后，受影响用户的旧独立对话也会从服务端会话列表中移除，读取、发送、编辑、撤回和重新生成等旧入口会被拒绝。原有数据库历史保留；恢复权限后可再次访问。

## 在普通聊天中调用

在消息输入框键入 `@`，出现有权限调用的身份候选；继续输入可过滤，点击候选插入内部名称。发送消息后身份在同一会话回复，头像、名称和左侧布局与其他用户相同。

上下文包含该会话中预算允许的历史文本与附件描述，每条带有发送者名称与发送时间；撤回内容排除，编辑记录使用最新内容。消息编辑本身不会再次触发模型。

## 独立对话

点击聊天界面的切换联系人按钮，选择身份，恢复本机上一次打开的独立对话，包括应用重启之后。此选择按服务器、账号和身份分别保存；若记录中的对话已删除，则选择现有对话，没有对话时新建一个。对话目录按当前身份与当前用户隔离，其他用户不能访问此目录。

- **新建对话**：建立没有旧对话上下文的新窗口，模型初始为自动选择；工具栏与对话目录中的新建入口行为一致。
- **切换对话**：显示已建立的独立对话目录，每项右侧提供删除按钮。删除前需确认，删除当前对话后自动切换到其他可用对话；全部删除后回到联系人选择界面。
- 对话名称显示在顶部居中位置，长名称会省略显示；点击名称可修改，手动名称不会被自动总结覆盖。
- 工具栏第一排提供新建、切换和删除对话；第二排提供模型与提示词设置，并显示最近成功回复实际使用的模型。尚无成功回复时显示首选模型或自动选择。
- “模型与提示词”的模型页支持搜索、复选和排序。选好多个模型后点击 **调整模型优先顺序**，在独立窗口中拖动模型行或把手，也可点击上下箭头；点击“完成排序”后，再保存对话设置。最上方优先调用，搜索不会清除已选项。每个独立对话保存自身的模型顺序，普通发送与重新生成均使用此顺序。提示词页可继承默认提示词或填写独立提示词，关闭继承并留空表示明确不使用系统提示词。
- 模型页的“保存为预设”可手动命名当前模型顺序；同名保存覆盖原预设。预设菜单可套用或删除，空模型列表也可保存为自动选择预设。套用后仍需保存对话设置才会写入服务器。预设只保存模型列表和顺序，不包含提示词；保存在当前设备，按服务器、账号和 AI 身份隔离。
- 可在外观设置中分别调整普通用户的气泡颜色、自动化身份（包括 API AI）的气泡颜色，以及“上下文外气泡”和“上下文外气泡文字”颜色。
- 外观定制页右上角提供 **保存配色预设** 文字按钮，输入名称后保存当前全部颜色，包括 AI 和上下文外气泡颜色；同名保存覆盖。预设方案区可切换，选中自定义预设后可删除。配色预设保存在当前设备并用于该设备的外观，不随聊天记录同步。

默认名称在首轮成功回复后由模型总结。若总结调用失败，对话仍可正常使用，可以手动重命名。

## 修改、撤回与重新生成

自己已发送的消息旁有消息操作菜单。文本消息可修改，各类型自己发送的消息可撤回；不能修改或撤回他人的消息和模型回复。原来的图片长按/右键保存和文件保存入口保留。

修改和撤回保留消息原来的 ID、时间与排列位置，更新会同步到同一会话各参与者和设备的本地记录。离线设备恢复连接后通过修订对账补齐更新。

普通聊天含 @ 的消息与独立 API 对话中的本人文本消息提供“重新生成回复”。重新生成使用该问题的最新编辑版本，以及截至该问题位置的历史上下文；不会混入此问题之后的旧答案和后续提问。新回复追加到当前会话，旧回复保留但被最新回复替代，不再传给模型。不同独立对话的记录不会混入。

### 上下文标记与清理

独立 API 对话中，服务端与实际模型调用共用同一套历史筛选和字符预算规则。未纳入上下文的消息以专用气泡颜色提示，不在气泡内附加上下文排除原因文字。排除情形包括原问题已撤回或删除、原问题已修改、已被重新生成的回复替代、调用失败提示、超出字符预算。仅保留末尾部分的消息仍按已纳入处理。旧版独立对话缺少问题关联字段的回复，按最近的用户问题关联；无法从旧数据恢复精确的编辑版本信息。

这些标记表示**当前历史在没有新增提问时的预算状态**，不是对上次模型请求的审计记录。新提问和发送者、时间等元信息会占用预算，可能进一步裁剪历史。可点击“刷新上下文状态”重新计算；未连接或服务端未升级时会提示状态不可用，而不是猜测。

已排除的 AI 回复在消息菜单提供“删除上下文外消息”，确认后移除正文并同步到该账号的其他设备，本地历史同步更新；离线设备重新连接也能补齐删除。删除无法恢复，服务端保留最小同步墓碑和原问题关联，避免旧回复在删除最新回复后重新进入上下文。不能使用此入口删除仍在上下文中的 AI 回复或普通用户消息；普通用户消息沿用仅本人可修改、撤回的规则。

## 更新顺序与验证

本功能同时涉及服务端、Manager 和客户端。先用新版 Manager 更新目标 VPS 服务端和身份配置，再替换 Windows 客户端的完整 Release 文件夹。只替换 exe 可能遗漏依赖文件。升级保留原数据库、媒体目录和证书，避免影响登录与聊天历史。

iOS 更新需在 macOS/Xcode 或对应构建环境生成并安装新版应用，仍需真机验证键盘 @ 候选、消息操作、媒体保存和对话切换。Windows 构建成功不能代替 iOS 验证。

旧消息缺少修订版本和新增线程字段时按默认值处理；未升级客户端可继续显示原始消息，但不能获得新修订同步与对话设置界面。
