## 1. 项目是什么

**QuickConect** 是一款面向私人小圈子（约 5-10 人）的即时通讯软件，全自研、数据自持。

- **服务端**：Go 语言，自签 TLS 证书，部署在上海腾讯云 VPS
- **客户端**：Flutter（Dart），一套代码编译四端：Windows / Android / iPhone / iPad
- **推送兜底**：ntfy.sh「推送铃」——App 被系统杀掉后，用一条不含消息内容的计数 ping 提醒用户（含 APNs/FCM）
- **安全**：客户端用**证书锁定**（pinning）校验服务器证书指纹，浏览器无法访问

**端口**：`https://124.223.44.151:8443`（WS 为 `wss://124.223.44.151:8443/api/ws`）

### 6.5 环境坑（踩过的，写在这里避免重蹈）

1. **PowerShell 脚本中文乱码**：`Write-Host` 含中文的 `.ps1` 必须用 **UTF-8 with BOM** 编码（`utf-8-sig`），否则 PowerShell 5.1 按 GBK 读会报语法错误
2. **msiexec 静默安装**：在 Git Bash 里 `msiexec //i ...` 参数会被转义搞坏。要么用 `powershell -Command "Start-Process msiexec.exe -ArgumentList '/i','xxx.msi' ..."`，要么直接提示用户双击 MSI（本项目非管理员权限也无法静默装）
3. **/tmp 在 Git Bash 与 Python 的路径不一致**：`/tmp` 在 Git Bash 可写，但 Windows 原生 Python 读不到。把临时文件写到项目目录或用 `C:/...` 绝对路径
4. **curl 中文 payload 传参**：`curl -d '{"中文":...}'` 在 Windows 控制台可能编码炸掉，先写 UTF-8 文件再 `-d @file`
