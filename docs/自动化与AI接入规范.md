# QuickConect 自动化发送者与 AI 接入规范

## 目标

AI、早报、告警、工作流等自动化发送者与普通用户使用同一套会话和消息协议。客户端只根据 `sender_name` 与 `sender_avatar_media_id` 展示消息，不显示 AI 或机器人标签；同一套协议也适用于人工账号。首期只提供通用协议与 Manager 配置，不绑定具体模型供应商。

## 身份模型

服务端为每个自动化发送者创建独立 service identity，包含稳定的 `id`、登录名、展示名、头像媒体 ID、启用状态和允许访问的会话列表。身份由服务端生成，客户端不能在发送请求中伪造 `sender_id` 或名称。自动化身份可以是 AI、早报、监控告警或任意外部系统。

头像通过普通媒体上传接口保存到服务端，`avatar_media_id` 随用户和消息返回；客户端缓存同一媒体 ID 的本地副本。更换头像不会改变历史消息中的发送者 ID。

## 消息接口

自动化发送复用 `POST /api/conversations/{id}/messages`：

```json
{
  "client_msg_id": "external-system-event-id",
  "type": "text",
  "payload": {"text": "早报内容", "source": "morning-brief"}
}
```

支持 `text`、`image`、`file`、`voice`、`sticker`。新增类型必须先加入服务端白名单和客户端降级渲染；未知类型应作为可读文本展示。服务端根据凭据绑定的 service identity 写入 `sender_id`，并广播统一的 `message.new` 事件。

## 触发方式

Manager 为每个自动化身份提供三种可同时启用的触发方式：自动计划（cron/间隔、时区、重试和并发）、手动立即运行（会话、模板参数和预览）以及外部 webhook（可撤销令牌、签名和时间窗口）。模型调用属于触发器的一部分，配置包括 provider、endpoint、model、temperature、token 上限、系统提示词和超时；密钥只保存在服务端，首期可以保存配置但不调用模型。

## 幂等、安全与运维

## 三种自动化模式

Manager 中的自动化身份分为三种模式：

1. **API 模式**：在群聊或私聊中 `@` 身份时触发模型调用。请求携带会话 ID、提问用户 ID、最近上下文和幂等键。默认模型可以留空，服务端按 Manager 配置的回退顺序逐个尝试；单独会话可以保存独立的目录 ID、历史上下文和模型选择。CLI Proxy API 可以填写为兼容 OpenAI API 的 endpoint，也可以只保存管理链接。
2. **Agent 模式**：在 API 模式基础上启用按用户隔离的记忆目录、联网搜索和受限服务器工具。每条记忆记录来源用户 ID、会话 ID 和时间。允许用户列表为空表示全部用户，否则只有列表中的用户可以单独选择该身份，群聊中也只有这些用户的 `@` 才会触发。
3. **Push 模式**：不调用模型，只接受 Manager 手动发送或外部 webhook 推送。目标可以是指定用户、指定会话，或两者同时推送。推送身份沿用普通消息展示，不增加机器人标记。

AI 身份的所有上下文和记忆都必须按用户 ID、身份 ID、会话 ID 分区，不能在不同用户之间共享。模型全部失败时返回普通错误消息，并且不写入错误的记忆上下文。

每次发送必须提供幂等键 `client_msg_id`，同一身份和会话重复提交返回第一次写入的消息。凭据支持作用域、过期、撤销和轮换；webhook 默认限流并记录来源 IP。审计记录身份、触发方式、会话、幂等键、结果、耗时和错误摘要，不记录密钥。Manager 提供运行日志、失败重试、限流计数和审计导出。

## Manager 配置页面

首期包括自动化身份列表、新建/编辑展示名与头像、启用状态、会话授权、Webhook 凭据、计划任务、模型连接配置、消息模板、测试发送、运行日志和审计。凭据加密存储，服务端 ARM64 与 x86_64 使用相同配置格式。

## 版本兼容

Manager 创建身份时选择 API、Agent 或 Push 模式。API 模式允许配置 CLI Proxy API 地址、默认模型和回退模型；默认模型留空时按回退列表依次尝试。Agent 模式额外配置记忆、联网搜索、服务器工具和允许用户 ID 列表；上下文键固定为 `identity_id:user_id:conversation_id`，确保不同用户和身份之间不串记忆。Push 模式配置推送目标类型（用户、会话或两者）和允许的外部来源。

新增字段必须向后兼容；头像和名称缺失时客户端回退到首字母。身份停用后历史消息仍可读，新的凭据请求返回 403。
